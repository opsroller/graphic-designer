# Visual identity

- Logo as vector source (SVG) with horizontal, stacked and icon-only
  versions; works in one colour and at 16 px.
- Palette with roles (primary, accent, surface, text, success, danger)
  and checked contrast pairs (WCAG AA).
- Type: one display, one text face, both under an allowed license.
- A one-page style guide in the project's design docs; exported tokens
  (colours, sizes) others can consume directly.
