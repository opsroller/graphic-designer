# App icons and store art

- Design the icon at full size and check it at the smallest size each
  platform shows; no text in icons.
- Export every size each store and OS requires from one vector or
  high-resolution source, by a committed script where possible.
- Store screenshots come from real gameplay captures, framed and
  captioned per each store's rules; keep a spec table per store.
