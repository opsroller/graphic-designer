*How-to guide, for anyone about to use a new font in a logo, app, game or website.*

# How to clear a font for use

This guide shows you how to confirm a font may be used everywhere you
intend to use it, and how to record it.

1. List the uses: designing on desktop, logo or wordmark, static images and
   store art, embedding in the app or game, serving as a web font,
   video, modification or subsetting.
2. Find the font's licence text (not the shop summary) and its source URL.
3. Check each use against the licence:
   - SIL Open Font License: all of the above are allowed; ship `OFL.txt`
     with any font file you distribute; do not sell the font alone; a
     modified version must drop any Reserved Font Name.
   - Commercial licence: confirm each use is covered; app and web uses are
     often separate purchases.
   - Platform system font: use only in that platform's UI; never bundle
     elsewhere or use in a logo unless its licence says so.
4. If any use is not covered, choose another font or buy the missing
   licence; ask the project manager if unsure.
5. Add a provenance log entry: font, version, source URL, licence, uses
   covered.
6. Put the licence file next to the font in the repository and give the
   front-end web developer any attribution line the credits page needs.

See the [design-licensing reference](../reference/skill-design-licensing.md).
