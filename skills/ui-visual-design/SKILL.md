# UI visual design

- Design components and their states (normal, hover/focus, pressed,
  disabled) before full screens.
- Hand off as specs plus exported assets and tokens, in the project's
  design folder; developers should never eyeball values.
- Check every screen at the smallest and largest target sizes and in
  colour-blind simulation.
