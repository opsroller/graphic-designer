*Reference, for anyone invoking or reviewing the `visual-identity` skill of the graphic-designer plugin.*

# visual-identity

| Field | Value |
|---|---|
| File | `skills/visual-identity/SKILL.md` |
| Use when | Creating, refreshing or extending a product's visual identity. |
| Inputs | Project profile; existing assets; requester's goals. |
| Outputs | Identity brief; category audit; three directions; logo system (primary, alternate lockups, symbol, wordmark, one-colour, small-size); palette with roles and light/dark values; type scale; icon and imagery style; four application mocks. |
| Docs owed | Explanation (rationale, rejected options) and reference (via brand-guidelines); how-to if the team applies it themselves. |

## Sections

- 1. Brief
- 2. Research (category audit, conflict check)
- 3. Explore three distinct directions
- 4. Logo system
- 5. Palette
- 6. Typography
- 7. Iconography and imagery style
- 8. Validate and hand over
