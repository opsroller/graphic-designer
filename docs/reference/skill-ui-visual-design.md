# ui-visual-design

| Field | Value |
|---|---|
| File | `skills/ui-visual-design/SKILL.md` |
| Use when | Designing app screens, menus, HUD and components for the UI developer. |
| Inputs | Identity and tokens; screen list and flows; platform and input targets; UI developer constraints. |
