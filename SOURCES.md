*Reference: the research sources behind the graphic-designer plugin.*

# Sources

All accessed 2026-10-18.

## Occupation, competencies and career levels

- O*NET OnLine, Graphic Designers 27-1024.00 — <https://www.onetonline.org/link/details/27-1024.00> — core tasks, skills, knowledge and tool categories of the occupation.
- AIGA, Designer 2025 — <https://educators.aiga.org/aiga-designer-2025/> — AIGA/NASAD competency framework context for communication design.
- AIGA Eye on Design, "What will a design job in 2025 look like?" — <https://eyeondesign.aiga.org/what-will-a-design-job-in-2025-look-like/> — systems thinking, brand consistency, stakeholder management, accountability; level differentiators.
- GitLab Handbook, Designer job family (marketing/brand) — <https://handbook.gitlab.com/job-families/marketing/designer> — junior vs intermediate brand designer scope.
- GitLab Handbook, Product Designer job family — <https://handbook.gitlab.com/job-families/product/product-designer> — senior, staff and principal expectations.
- Senior Graphic Designer posting (AppNation, Lever) — <https://jobs.lever.co/appnation/01cf7569-b623-4f92-a4f8-8f41dc162489> — store asset ownership (screenshots, feature graphics), brand systems, visual audits.
- Senior Brand Designer posting (Grindr, via designproject.io) — <https://designproject.io/jobs/senior-brand-designer-at-grindr-wnc6hm> — building brand systems, templates and toolkits, concept to production files, mentoring.

## Brand guidelines and design tokens

- aytm, "Developing Brand Identity Guidelines, Part 2: What's in a Brand Identity Manual" — <https://aytm.com/post/developing-brand-identity-guidelines-part-2> — sections of a brand manual, clear space, minimum size, misuse.
- W3C Design Tokens Community Group, Design Tokens Format Module 2025.10 — <https://www.w3.org/community/reports/design-tokens/CG-FINAL-format-20251028/> — token file format, types, groups, aliases, colour values.
- Apple Human Interface Guidelines, Branding — <https://developer.apple.com/design/human-interface-guidelines/branding> — accent colour use, custom fonts, branding deferring to content.

## Icons and platform specs

- Apple Human Interface Guidelines, App icons — <https://developer.apple.com/design/human-interface-guidelines/app-icons> — layers, shapes, appearances, text and photo guidance, per-platform sizes, colour spaces.
- Apple Developer, Creating your app icon using Icon Composer — <https://developer.apple.com/documentation/xcode/creating-your-app-icon-using-icon-composer> — canvas sizes, layer preparation and export rules.
- Android Developers, Adaptive icons — <https://developer.android.com/develop/ui/compose/system/icon_design_adaptive> — 108 dp layers, 66 dp safe zone, monochrome themed icons.
- Android Developers, Google Play icon design specifications — <https://developer.android.com/google-play/resources/icon-design-specifications> — 512 px store icon, keylines, no baked masks or ranking text.
- Material Design (legacy M1), Icons — <https://m1.material.io/style/icons.html> — system icon grid, live area, keylines, stroke and corner rules.

## Store listing art

- Google Play Console Help, Preview assets — <https://support.google.com/googleplay/android-developer/answer/9866151> — feature graphic, screenshots, video, prohibited content.
- Apple App Store Connect Help, Screenshot specifications — <https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications> — required iPhone and iPad sizes, formats, counts.
- Steamworks, Store graphical assets — <https://partner.steamgames.com/doc/store/assets/standard> — capsule and screenshot sizes.
- Steamworks, Library assets — <https://partner.steamgames.com/doc/store/assets/libraryassets> — library capsule, hero, logo and safe area.
- Steamworks, Graphical asset rules — <https://partner.steamgames.com/doc/store/assets/rules> — allowed and forbidden capsule content.

## Accessibility

- W3C, Understanding SC 1.4.11 Non-text Contrast — <https://w3c.github.io/wcag/understanding/non-text-contrast> — 3:1 for UI components, states, icons, charts; exceptions.
- WebAIM, Contrast and Color Accessibility — <https://webaim.org/articles/contrast/> — 1.4.3 thresholds, large-text definition, no rounding, exemptions, text on images.

## Licensing

- SIL Open Font License FAQ — <https://fontlibrary.org/files/BSozoo/130/OFL-FAQ.txt> — embedding, bundling, web fonts, Reserved Font Names, artwork made with OFL fonts.

## Documentation

- Project Diataxis guide (from <https://diataxis.fr>) — structure and kinds of every docs page and the docs steps in each workflow.
