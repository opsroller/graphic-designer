# Brand guidelines checklist

Tick each before calling the guidelines done.

## Logo
- [ ] Primary, horizontal, stacked, symbol-only and wordmark-only versions
- [ ] Construction drawing with the clear-space unit marked
- [ ] Clear space rule as a multiple of that unit
- [ ] Minimum size per lockup: px (screen) and mm (print, if in scope)
- [ ] Full-colour, one-colour dark, one-colour light (reversed) versions
- [ ] Backgrounds each version may sit on (with examples on photos)
- [ ] Small-size simplified mark if the full mark fails below ~32 px
- [ ] At least six misuse examples drawn from the real mark
- [ ] File formats listed: SVG (screen), PDF/EPS (print), PNG at stated sizes

## Colour
- [ ] Primitive ramps with every step's value
- [ ] Semantic roles: brand, accent, surface(s), on-surface, outline,
      success, warning, danger, info, focus, disabled
- [ ] Light and dark mappings for every role
- [ ] Approved text/background pairs with measured contrast ratio
- [ ] Icon/background and control/background pairs at 3:1 or better
- [ ] Usage proportions and colours never to combine
- [ ] Print values only if print is in scope (CMYK, spot reference)

## Typography
- [ ] Families, weights, styles used
- [ ] Scale: size, line height, weight, letter-spacing per step
- [ ] Fallback stack per platform
- [ ] Script coverage and the fallback for scripts the font lacks
- [ ] Licence summary per family and use (desktop, app, web, logo, video)

## Iconography and imagery
- [ ] Icon grid, live area, stroke, corner radius, fill rules
- [ ] Link to the icon library source
- [ ] Illustration style with examples
- [ ] Photography or capture direction with examples and don'ts

## Layout and templates
- [ ] Spacing scale (matches tokens)
- [ ] Grid(s) per format
- [ ] Templates: social post, store capsule, press image, slide, as needed

## Delivery
- [ ] Tokens file (`.tokens.json` or the profile's format) committed
- [ ] Guide in the project's docs, linked from the docs index
- [ ] Change log at the top with version and date
- [ ] Provenance log entries for every font and image used
